SYSTEM DESIGN / FLIGHT COMPUTING

Zynq flight computer

A reusable Linux platform for rocketry avionics.

Used during a successful 5.5 kN liquid-engine test firing, managing sensing, control, telemetry, and data acquisition.

Project details

Linux runs the high-level software. FPGA fabric and expansion interfaces support mission-specific functionality.

Compute
Xilinx Zynq XC7Z030 · 1 GB DDR3 · eMMC
Interfaces
Gigabit Ethernet · Wi-Fi · FMC expansion · PCIe
Sensing
IMU · barometer · temperature · GNSS
Power
USB-C or battery, with integrated power-path multiplexing

Responsibility: complete system design, hardware, embedded software, bring-up, integration, and test validation.
